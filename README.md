# Materiais usados:
Item	Para que serve
Raspberry Pi (3B+, 4 ou 5)
	Computador que exibe o projeto
Cartão microSD 32 GB	
Sistema operacional
Fonte oficial do modelo de Pi
	Energia estável para o Pi
Monitor com HDMI e furação VESA
	Tela do projeto
Cabo HDMI ou micro-HDMI → HDMI
	Ligar o Pi ao monitor
Case com ventilação para o Pi	Proteger e resfriar o Pi
Suporte VESA (braço, parede ou pedestal)
	Fixar o monitor
Caixa de proteção com frente transparente	Proteger contra fluido de corte e cavaco
Filtro de linha	Energia em tomada própria
Canaleta e abraçadeiras
	Organizar os cabos

Botões grandes + jumpers, ou teclado numérico USB
	
Trocar página e dar zoom

Teclado e mouse USB	Configuração inicial
