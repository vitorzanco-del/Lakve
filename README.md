# APRESENTAÇÃO DO PROJETO 

Nosso objetivo é trazer uma solução para o problema de visualizaçâo das máquinas de torno CNC, atualmente o professor necessita de ir até a maquiná para realizar esta tarefa, nossa solução busca otimizar isto de forma tecnológica, a ideia do nosso projeto seria ter um monitor ao qual o professor poderia visualizar as máquinas sem precisar ter que ir pessoalmente até elas, por este monitor também seria possível transmitir para toda a turma a maquiná em si, através de uma projeção. 


# FUNCIONAMENTO DO PROJETO 

Dividimos as equipes em quatro, cada uma responsável por uma parte do projeto.

--- Lakave:
 Esta equipe está responsável pela documentação do projeto.

--- Cominic CNC:
 Responsável por Servidor, Frontend x Backend.

--- Thirteentech:
 Vão fazer as entrevistas, fazer as medidas, tirar fotos e vídeos, Organização das equipes.

--- Axión:
 Vai fazer Fazer montagem do contêiner do Raspberry, provavelmente via impressão 3D, Instalar o sistema operacional no raspberry é Instalar o Raspberry no monitor.  


# Materiais usados
Item	Para que serve
Raspberry Pi (3B+, 4 ou 5)
	Computador que exibe o projeto
Cartão microSD 32 GB	
Sistema operacional
Fonte oficial do modelo de Pi
	Energia estável para o Pi
Monitor com HDMI e furação VESA
	Tela do projeto
Cabo HDMI ou micro-HDMI → HDMI
	Ligar o Pi ao monitor
Case com ventilação para o Pi	Proteger e resfriar o Pi
Suporte VESA (braço, parede ou pedestal)
	Fixar o monitor
Caixa de proteção com frente transparente	Proteger contra fluido de corte e cavaco
Filtro de linha	Energia em tomada própria
Canaleta e abraçadeiras
	Organizar os cabos

Botões grandes + jumpers, ou teclado numérico USB
	
Trocar página e dar zoom

Teclado e mouse USB	Configuração inicial
